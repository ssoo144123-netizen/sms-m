SmsPro - راهنمای نصب و استفاده

۱. ساخت APK در GitHub
   - یک repository جدید بسازید و محتوای این پوشه را داخلش آپلود کنید.
   - فایل .github/workflows/main.yml باید پر باشد.
   - به تب Actions بروید. بعد از سبز شدن، فایل smspro-apk را از بخش Artifacts دانلود کنید.

۲. نصب
   - APK را روی گوشی نصب کنید (نصب از منابع ناشناس را فعال کنید).
   - اگر نسخه قدیمی را دارید، اول حذفش کنید.

۳. اولین اجرا
   - دسترسی‌های پیامک را بدهید (خواندن، ارسال، دریافت).
   - وقتی پیام «پیامک‌رسان پیش‌فرض» آمد، «تنظیم» را بزنید و SmsPro را انتخاب کنید.
   - بدون این کار، دریافت و حذف پیامک کار نمی‌کند.

۴. امکانات
   - جستجو در لیست گفتگوها و داخل هر گفتگو
   - فیلتر همه / خوانده‌نشده / خوانده‌شده
   - انتخاب چندتایی، حذف، خوانده/نخوانده، ذخیره در فایل متنی (پوشه Download)
   - ارسال پیامک
   - تنظیمات: رنگ اصلی (۷ رنگ) و حالت تیره

۵. نکته
   - برای برگشت به پیامک‌رسان قبلی، در تنظیمات گوشی برنامه پیش‌فرض پیامک را دوباره تغییر دهید.
   - پیام‌های MMS (تصویری) پشتیبانی نمی‌شوند.
